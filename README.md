## Como adicionar imagens

1. Acesse o repositório no GitHub
2. Clique em **Add file → Upload files**
3. Faça upload das fotos na pasta `assets/` com os nomes exatos da tabela acima
4. Formatos aceitos: `.jpg` ou `.png`
5. As imagens aparecem automaticamente nos cards — enquanto não existirem, os cards exibem um gradiente de cor como fallback

Para o logo, salve como `assets/logo.png`.
