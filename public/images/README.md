# 📁 Onde colocar as fotos

Faça upload dos arquivos **diretamente nesta pasta** pelo GitHub
(Add file → Upload files) e respeite os nomes abaixo — o código já está
apontando para eles.

---

## Fotos obrigatórias (raiz de /images)

| Arquivo       | Onde aparece               | Tamanho ideal  |
|---------------|---------------------------|----------------|
| `hero.jpg`    | Foto de fundo da capa      | 2000×1300 px   |
| `about.jpg`   | Foto do fundador / equipe  | 900×1200 px    |

---

## Galeria (pasta /images/galeria)

Coloque de 6 a 10 fotos nomeadas em sequência:

| Arquivo    | Sugestão de conteúdo            |
|------------|---------------------------------|
| `01.jpg`   | Circuito Emendadas              |
| `02.jpg`   | Circuito Américas               |
| `03.jpg`   | Circuito Andorinhas             |
| `04.jpg`   | Circuito Betânia                |
| `05.jpg`   | Circuito Ponta Verde            |
| `06.jpg`   | Circuito Rancharia              |
| `07.jpg`   | Foto extra (lagoa, duna, etc.)  |
| `08.jpg`   | Foto extra                      |

> **Formato:** JPG ou JPEG  
> **Tamanho:** máximo 800 KB por foto (redimensione antes se precisar)  
> **Proporção galeria:** qualquer — o carrossel já ajusta

---
